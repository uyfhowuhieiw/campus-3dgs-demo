# 校园实景 · 教室 3D 体验

面向手机和电脑的静态 3DGS 展示网页。所有网页资源与模型均位于本仓库，使用 GitHub Pages 托管。

点击“进入三维场景”加载模型；单指旋转，双指缩放。“分享链接”复制当前网页地址，可粘贴到微信。

模型来源：本地 Brush 25000 步训练结果，366318 个高斯。手机展示使用约 11.7 MB 的标准 SPLAT 文件，保留全部高斯位置、尺寸、旋转与透明度，颜色使用 SH0。原始 PLY 不包含在此公开仓库中。

渲染器：[Reall3dViewer](https://github.com/reall3d-com/Reall3dViewer)，MIT 许可。相关许可文件随仓库提供。
